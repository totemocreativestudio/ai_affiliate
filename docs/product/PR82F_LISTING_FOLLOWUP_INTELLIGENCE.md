# PR #82F — Listing Follow-Up Intelligence

Continue PR #82E by turning follow-up channel data into useful operational insight.

Add to Listings:
- summary cards: WhatsApp, DM Instagram, DM TikTok, Other Channels
- channel distribution
- number of Reach Out / Follow Up / Negotiation activities per channel
- current Won/Active listings grouped by latest follow-up channel
- No Response activities per channel
- conversion signal = current Won/Active listings / listings using that channel
- compact channel insight panel, not a separate AI-looking dashboard
- obey workspace isolation and existing date/platform/stage filters where practical

No automated claim that a channel caused conversion; label it as an operational association/signal only.
